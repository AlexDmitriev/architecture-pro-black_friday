# 1. Запуск приложений

## Как запустить

Запустить любое приложение можно следующим образом: 
1) заходим в каталог с приложением [sharding-repl-cache/](sharding-repl-cache),  запускаем mongodb и приложение:

```shell
docker compose up -d
```

2) Заполняем mongodb данными (каждый каталог содержит свой ./scripts/mogno-init.sh с установленным правами на запуск):

```shell
./scripts/mongo-init.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
